Have you heard about Jev?

Jev, Laya, and the other System One models make typed decisions in a single forward pass: no token generation, no hallucinated labels, calibrated probabilities on every option, in tens of milliseconds.

Well, you have it now in the WebAI Studio extension, all locally in your browser. Every page you visit gets window.Classifier, a polyfill of the proposed Classifier API, backed by the open Laya decision encoder running on LiteRT.js.

  • Three question types: binary, categorical, ordinal. Any number of questions per call.
  • Explainer-shaped results: a record keyed by question id with label, confidence, and probabilities.
  • Model downloaded once from Hugging Face, then cached. Nothing you classify leaves the device.
  • Full support in the DevTools panel: history, diagnosis, model management, and a playground.

Getting Started

1

Open Developer Tools

Right-click anywhere on a webpage and select Inspect, or use the keyboard shortcut.

F12 or Ctrl + Shift + I or Cmd + Option + I
2

Locate the "WebAI" Panel

Look for the WebAI tab in the top navigation bar of DevTools. If you don't see it, click the double arrows (>>) to show more tabs.

3

Verify Environment

Check the Overview tab to ensure Built-In AI APIs are available and the required flags are enabled.
