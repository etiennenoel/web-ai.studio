Where each kind of hardware is heading

The table at the top of the page shows one year at a time. This is every year at once — the average speed each category of machine manages on a given size of model, from {{ yearRangeLabel }}, and where its own trend points next.

Each line is fitted from that category's own history and nothing else. It is not a roadmap or a leak; it is what the last decade implies if the last decade continues.

How to read it

  1. The solid line is measured hardware, averaged per year. Dashed beyond it is extrapolation, on the shaded side of the chart.

  3. Where a line stops or never starts, either the machines of that category cannot hold the model, or the source has no figure for it — the Tiny row is measured only, never modelled.
