Supported Columns & Copy-Paste Instructions

Copy & Paste: Copy the template, fill in your rows, copy the sheet (including the header row), and paste it directly into the Context cell of the first row below.

Matched Headers (any order): Context, Input (Text), Input (Images), Input (Audio), Schema, Sampling Mode, API, Summarizer Length, Summarizer Type, Summarizer Speed Preference. Unrecognised or omitted columns are ignored.

Media & Options: Pictures placed in Input (Images) cells are downloaded into the row whether loaded via URL/file or pasted. Input (Audio) takes a full URL (e.g. https://web-ai.studio/images/cortex/speeches/spontaneous-speech-en-46.mp3). Schema takes a JSON Schema or a /regex/flags literal (Prompt rows only). The three Summarizer columns accept short/medium/long, key-points/tldr/teaser/headline, and auto/speed/capability.
