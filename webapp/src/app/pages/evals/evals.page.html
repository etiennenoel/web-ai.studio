Import from Sheets

  1. Copy the template and fill in your rows.
  2. Copy the sheet — including the header row — and paste it into the Context cell of the first row below.

Headers are matched by name in any order: Context, Input (Text), Input (Images), Input (Audio), Schema, API. Columns you leave out are simply not imported, and any column the page does not recognise is ignored.

Put pictures straight into the Input (Images) cells — they come across with the paste and are downloaded into the row. An Input (Audio) cell takes a full URL, for example https://web-ai.studio/images/cortex/speeches/spontaneous-speech-en-46.mp3. A Schema cell takes a JSON Schema or a /regex/flags literal, and applies to Prompt rows only.
