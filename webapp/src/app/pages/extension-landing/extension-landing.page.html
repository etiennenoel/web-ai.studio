Chrome DevTools Panel

One inspector for all of Chrome's Built-In AI APIs

Chrome's Built-In AI APIs expose on-device models like Gemini Nano directly to web pages via native JavaScript globals (LanguageModel, Summarizer, Translator, LanguageDetector, Proofreader, Writer, and Rewriter). The WebAI DevTools panel adds a dedicated tab to Chrome DevTools so you can manage model downloads, test prompts, profile token speed, inspect live API calls, and route requests to cloud or local fallbacks.
