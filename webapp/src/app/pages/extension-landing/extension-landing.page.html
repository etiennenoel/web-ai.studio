New in v0.12.0 Classifier API polyfill

Have you heard about Jev?
It is in your browser now.

Jev, Laya, and the other System One models make typed decisions in one forward pass: no token generation, no hallucinated labels, calibrated probabilities on every option, in tens of milliseconds.

The WebAI extension now polyfills the proposed Classifier API on every page you visit: window.Classifier, backed by the open Laya decision encoder running locally with LiteRT.js. It stays the DevTools companion for all of Chrome's built-in AI APIs.
